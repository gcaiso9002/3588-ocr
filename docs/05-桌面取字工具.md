# 05 · 桌面取字工具（Windows）

仿天若OCR / 白描电脑版：**全局快捷键 → 框选 → 出字 → 进剪贴板**。

识别跑在 RK3588 板子的 NPU 上，电脑这边只负责截图、选区、取词、复制/粘贴。

```
desktop/
├── npu_ocr_gui.py            主程序
├── npu_ocr_gui_config.json   配置
├── npu_ocr_client.py         命令行客户端（也放在这里）
├── start_npu_ocr.bat         启动器
└── README.md
```

---

## 用法

```powershell
pip install pillow pywin32 pystray
python npu_ocr_gui.py
```

按 **Ctrl+1** → 拖框 → 出字。

* 选区外自动压暗，右下角有 2 倍放大镜
* **Esc** 取消
* 结果窗口：**复制** / **粘贴** / **重新识别** / **设置**
* 默认「识别后自动复制到剪贴板」，Ctrl+V 直接用
* 也可勾选「识别后自动粘贴回原窗口」
* 托盘图标 → 截图取字 / 设置 / 退出

命令行：

```powershell
python npu_ocr_gui.py              # 常驻
python npu_ocr_gui.py --shot       # 启动后直接进截图模式
python npu_ocr_gui.py --selftest   # 自检：抓屏 → 裁一块 → 调板子
python npu_ocr_gui.py --log app.log --save-dir ./crops   # 带日志和截图存档
```

## 配置（`npu_ocr_gui_config.json`）

| 键 | 默认 | 说明 |
|---|---|---|
| `server` | `http://192.168.31.230:8766` | 板子上的服务地址 |
| `server_candidates` | `["http://192.168.31.40:8766"]` | 连不上时自动探测的备用地址 |
| `hotkey` | `ctrl+1` | 全局快捷键 |
| `auto_copy` | true | 识别后自动复制 |
| `auto_paste` | false | 识别后自动粘贴回原窗口 |
| `magnifier` | true | 截图放大镜 |
| `keep_result_window` | false | 结果窗口不自动关闭 |

板子 IP 变了改 `server` 即可；加进 `server_candidates` 则连不上时会自动找。

## 三个必须注意的实现细节

### 1. Tk 不是线程安全的

全局热键由 `RegisterHotKey` 的独立线程收到，**绝不能在那里直接建窗口**，
否则窗口几何会随机错位（实测选区原点每次都不一样，窗口 rect 跑到屏幕中间）。

```python
hk = Hotkey(spec, lambda: self.root.after(0, self.start_capture))
```

所有 UI 操作都要 `after()` 调度回主线程。

### 2. 多屏 + 不同 DPI 的坐标换算

用户机器：主屏 3840×2160 @150%，副屏 1080×1920 在**左侧 X=-1080**，
虚拟桌面 4920×2352。

必须在**建任何窗口之前**设成 per-monitor DPI aware：

```python
ctypes.windll.user32.SetProcessDpiAwarenessContext(ctypes.c_void_p(-4))
```

之后 **Tk 事件坐标 = 物理像素 − 虚拟桌面原点**，与
`ImageGrab.grab(all_screens=True)` 同一坐标系，1:1 无缩放，直接 crop 即可。

（Tk 自己认为屏幕只有主屏 3840×2160，别信它的 `winfo_screenwidth()`。）

### 3. 全局热键用 ctypes，不用第三方库

```python
user32.RegisterHotKey(None, 0xBEEF, mods | MOD_NOREPEAT, vk)
# 然后在自己的线程里 GetMessageW 循环
```

`hWnd` 传 `None`，热键消息会投递到调用线程的消息队列。**不需要管理员权限。**

## 热键冲突

`RegisterHotKey` 返回失败、错误码 **1409 = ERROR_HOTKEY_ALREADY_REGISTERED**，
说明被别的程序占了（滴答清单、各种截图/录屏工具都可能占）。

程序的做法是**通用降级**，不写死哪几个键空闲：保持配置的修饰键不变，
换一批键名再试（`2 3 4 5 6 7 8 9 0 q w e r s d f g z x c v b f2…`），
再试 `ctrl+alt+*` / `ctrl+shift+*`。第一个能用的就它，并弹窗告诉用户换成了哪个。

> 这台机器上 `Ctrl+Alt+A`、`Ctrl+Shift+A`、`Ctrl+Alt+D`、`Ctrl+1` 都被占过。
> `Ctrl+1` 原本被 **白描桌面版**占着——把它卸掉就干净了。

`tools/test_gui_e2e.py`：置顶一个内容已知的窗口 → 启动程序 → 发 Ctrl+1 →
拖一个框 → 检查剪贴板。

known-text window at 600,400 900x260

> 量出来的选区会差 1.5 倍——很容易误判成 app 的 bug。

## 已知限制

* 结果窗口是 Tk 原生控件，不是天若那种毛玻璃圆角风
* 放大镜是 2 倍最近邻放大，没有像素级取色器
* 一次只框一个区域，不支持多选区
* 选区必须是屏幕上的东西（不能框网页里的空白滚动区）
